# [下載及使用方法](https://fungltf-kok2.github.io/kok2-godot/)

1. 下載以下三個 ZIP 檔案。
   - [Game Core](https://github.com/fungltf-kok2/kok2-godot/releases/download/v0.4.1/GKK2-Core-0.4.1-Windows.zip)（約 113 MB）
   - [Pack1](https://github.com/fungltf-kok2/kok2-godot/releases/download/v0.4.0/GKK2-Pack1-v2.zip)（約 176 MB）
   - [Pack2](https://github.com/fungltf-kok2/kok2-godot/releases/download/v0.4.0/GKK2-Pack2-v2.zip)（約 1.5 GB）
2. 將三個 ZIP 解壓至同一位置，合併解壓後的 `GKK2` 資料夾。
3. 開啟 `GKK2\GKK2.exe`，於登入畫面註冊帳號或登入。

[查看使用方法](https://fungltf-kok2.github.io/kok2-godot/)
